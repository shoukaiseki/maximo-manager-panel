#  应用信息导入导出以及导入导出规范定制

这几个表是应用关联的表,不要执行,只是告诉你这几个表的作用,下面导入导出用得到
```
--显示的应用名
delete from maxapps where app='ITEM_ITEM';
--xml
delete from maxpresentation where app='ITEM_ITEM';
--签名
delete from sigoption where app='ITEM_ITEM';
--权限组
delete from applicationauth where app='ITEM_ITEM';
--页面label等设置
delete from maxlabels where app='ITEM_ITEM';
--菜单配置
--MENUTYPE='APPMENU' 选择操作
--MENUTYPE='APPTOOL' 工具栏
--MENUTYPE='SEARCHMENU' 查找菜单
delete from maxmenu where moduleapp='ITEM_ITEM' and menutype !='MODULE';
delete from maxmenu where moduleapp='ITEM_ITEM' and elementtype='APP' and keyvalue='ITEM_ITEM';
delete from maxmenu where keyvalue = 'ITEM_ITEM';
delete from appdoctype where app= 'ITEM_ITEM';
```

### 对象处理脚本规范
对象行格式化,新增/修改/删除 基础脚本存储目录 E:/gitwork/wushiling/jsproject/masscript/cn/shoukaiseki/tools/migrate

脚本名以 SKS_MIGRATE_<对象名> 的方式命名，如 SKS_MIGRATE_MAXAPPS 

脚本以java静态方法的方式编写,供其他脚本以下方式调用

```

smMaxApps.getScriptSigoption(config)
```
